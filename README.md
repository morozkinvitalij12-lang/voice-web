# VoiceSiteLauncher — голосовое открытие сайтов

Приложение для Windows 10/11 (64 бит): удерживайте физические клавиши **V + F6**, произнесите фразу, отпустите **обе** клавиши. Речь распознаётся локально через faster-whisper, затем сайт открывается в браузере по умолчанию.

## Файлы

- `main.py` — трей, клавиши, обработка событий, проверка прав и автозапуск.
- `audio_recorder.py` — микрофон по умолчанию, mono float32, 16 кГц, запись исключительно в RAM.
- `recognizer.py` — faster-whisper, автоопределение языка, выбор CUDA/CPU.
- `site_router.py` — расширяемый словарь сайтов и поиск Google.
- `requirements.txt` — закреплённые версии прямых зависимостей.
- `test_app.py` — автоматические тесты без нажатий клавиш и открытия браузера.
- `Запустить.cmd` — запуск двойным кликом; при первом запуске создаёт окружение и устанавливает зависимости.

## Установка с нуля

### 1. Скачать и распаковать проект

1. Откройте репозиторий `morozkinvitalij12-lang/voice-web` на GitHub.
2. Нажмите зелёную кнопку **Code → Download ZIP**.
3. Щёлкните архив правой кнопкой и выберите **«Извлечь всё»**.
4. Откройте распакованную папку: в ней должны лежать `main.py`, `requirements.txt` и `Запустить.cmd`.

Не запускайте приложение прямо из ZIP. Храните все файлы вместе. Виртуальное окружение и модель не поставляются в репозитории: они создаются на вашем компьютере при установке и первом запуске.

Если установлен Git, вместо ZIP можно выполнить:

```bat
git clone https://github.com/morozkinvitalij12-lang/voice-web.git
cd voice-web
```

### 2. Установить Python

Нужен **Python 3.12, 64 бит**. Скачайте установщик с официального сайта Python. На первом экране отметьте **Add python.exe to PATH**, затем выполните установку. После установки откройте новый терминал.

Проверьте:

```bat
python --version
```

Должна отображаться версия `Python 3.12.x`. Если команда открывает Microsoft Store или не найдена, проверьте установленный Python и настройку PATH; не продолжайте, пока команда не начнёт работать.

### 3. Подготовить первый запуск

При первом запуске из следующего шага **`Запустить.cmd`** автоматически создаст `.venv` в распакованной папке и установит библиотеки из `requirements.txt`. Дождитесь завершения: для первой установки нужен интернет. При ошибке окно останется открытым с сообщением; приложение не запустится с недоустановленными библиотеками. Если загрузка прервалась, устраните причину и снова откройте этот файл.

Поддерживаются стандартные папки установки Python для пользователя и всех пользователей, а также Python Launcher (`py -3.12`) для нестандартной установки. Обычные последующие запуски не вызывают `pip`, если библиотеки уже доступны. Сам Python установите отдельно: ZIP содержит исходники, не автономный EXE.

Можно установить зависимости вручную. В Проводнике откройте распакованную папку проекта, в адресной строке введите `cmd` и нажмите Enter. По очереди выполните:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для подготовки окружения права администратора не нужны. Активация окружения и изменение ExecutionPolicy не нужны. Папка `.venv` должна оставаться рядом с `main.py`; после её удаления файл запуска подготовит её заново. Не переносите `.venv` с другого компьютера или из другой папки: создайте её на месте.

### 4. Запустить двойным кликом и разрешить UAC

1. Дважды щёлкните **`Запустить.cmd`** — это основной файл для обычного запуска.
2. Если приложение спрашивает **«Перезапустить с повышенными правами?»**, нажмите **«Да»**.
3. Затем Windows спросит **«Разрешить этому приложению вносить изменения на вашем устройстве?»** — тоже нажмите **«Да»**, если вы запускаете скачанный и проверенный проект.
4. Если Windows просит пароль администратора, его должен ввести владелец административной учётной записи. Программа не обходит это ограничение.
5. Дождитесь **зелёного микрофона в системном трее** справа внизу. В первый раз модель скачивается, поэтому подготовка может занять несколько минут.

Можно также нажать правой кнопкой на `Запустить.cmd` → **«Запуск от имени администратора»**; в Windows 11 этот пункт иногда находится в **«Показать дополнительные параметры»**. При отказе в повышении программа завершается.

Окно командной строки при запуске через этот файл быстро закрывается — это нормально: программа остаётся в трее. Если значок не появился, воспользуйтесь консольным запуском из следующего раздела, чтобы увидеть причину. Не открывайте `main.py` двойным кликом: файловая ассоциация Windows может выбрать другой Python, без установленных зависимостей.

## Запуск от администратора

Откройте «Терминал» или командную строку **от имени администратора**, перейдите в папку проекта и запустите:

```bat
.venv\Scripts\python.exe main.py
```

В приложении предусмотрена обязательная проверка прав для работы с `keyboard`, согласно требованиям проекта. Если запуск не повышенный, появится предупреждение с предложением перезапуска; после согласия Windows запросит разрешение UAC. При отказе приложение завершается. Сама библиотека `keyboard` на Windows не во всех сценариях требует повышенных прав, но здесь запуск от администратора установлен явно.

Первый запуск выводит **«Загрузка модели...»**. При отсутствии модели требуется интернет: `base` занимает примерно 150 МБ, `small` — примерно 500 МБ. Точный размер и время загрузки зависят от версии модели и соединения. Подождите зелёного микрофона в трее. Пока модель загружается, клавиши не включены.

Модель кэшируется в:

```text
%LOCALAPPDATA%\VoiceSiteLauncher\models
```

После скачивания модель загружается сначала только из локального кэша. **Распознавание не использует облачные API и работает без интернета.** Для открытия сайтов и поиска интернет, разумеется, нужен.

Фоновый запуск без консольного окна:

```bat
.venv\Scripts\pythonw.exe main.py
```

Повторный экземпляр не запускается. Для завершения откройте меню значка микрофона в трее и выберите **«Выход»**. Если выполняется загрузка модели или распознавание, выход дождётся завершения этой операции, затем освободит микрофон и клавиатурный hook; браузер после запроса выхода не открывается. Значок остаётся до завершения. В Windows контекстное меню открывается правой кнопкой мыши. Если значок скрыт, откройте стрелку области уведомлений и включите постоянное отображение в параметрах панели задач.

## Как пользоваться

1. Убедитесь, что значок микрофона зелёный.
2. Зажмите V и F6 в любом порядке: запись начинается после нажатия второй клавиши.
3. Скажите, например, «открой ютуб», «open Wikipedia» или «погода завтра».
4. Отпустите клавиши в любом порядке: запись и обработка заканчивают этап записи **только после отпускания последней из двух клавиш**.
5. Дождитесь открытия сайта. Во время распознавания новые записи не принимаются.

Цвета значка: серый — загрузка; зелёный — готовность; красный — запись либо ошибка запуска; жёлтый — распознавание. Подсказка при наведении уточняет состояние.

Используются физические scan-коды V (`0x2F`) и F6 (`0x40`): в русской раскладке та же клавиша подписана «М». Автоповтор клавиатуры не перезапускает запись. Клавиши **не блокируются** для других приложений: V может вводиться в активное поле, а F6 — выполнять обычное действие. Не используйте сочетание в поле пароля. После потери событий клавиатуры, например при блокировке Windows, нажмите и отпустите обе клавиши либо перезапустите приложение.

Рекомендуемая длина фразы — 1–15 секунд. Минимум — 0,25 секунды, максимальный буфер — 120 секунд. Если лимит превышен, лишнее аудио не сохраняется; после отпускания клавиш появится сообщение о слишком длинной записи.

## Модели, языки и CUDA

По умолчанию применяется многоязычная модель `base` с автоопределением языка. Отдельные фразы на русском и английском поддерживаются без переключателя. Очень короткие фразы и смешение языков могут распознаваться хуже; для лучшего качества выберите `small`:

```bat
.venv\Scripts\python.exe main.py --model small
```

На CPU используется INT8. При обнаружении NVIDIA GPU приложение пробует CUDA с INT8/FP16. **Одного наличия видеокарты недостаточно**: CTranslate2 также нужны совместимые библиотеки CUDA 12/cuBLAS и cuDNN 9 в PATH либо в пакетах окружения. Ошибка загрузки или исполнения CUDA приводит к повтору на CPU, включая ошибки ленивого генератора распознавания.

Для установки необязательных библиотек NVIDIA в это же окружение:

```bat
.venv\Scripts\python.exe -m pip install nvidia-cublas-cu12==12.9.3.13 nvidia-cudnn-cu12==9.28.1.4
```

Эти пакеты крупные и не нужны для CPU. Приложение добавляет их каталоги DLL в пути загрузки Windows. Драйвер NVIDIA должен поддерживать установленные библиотеки.

Принудительный CPU:

```bat
.venv\Scripts\python.exe main.py --device cpu
```

`--device cuda` пробует GPU, но также возвращается к CPU при его недоступности. Никакой CUDA Toolkit или PyTorch для обычного CPU-запуска не требуется.

## Сайты и поиск

В `site_router.py` находится словарь `SITE_KEYWORDS`: URL → кортеж фраз. Уже добавлены YouTube, Google, VK, Telegram Web, Wikipedia, GitHub, Stack Overflow, Reddit, Twitch, Ozon, Wildberries, Avito и Habr.

Для расширения добавьте запись в словарь. Сопоставление нечувствительно к регистру и учитывает границы слов, поэтому «вк» не совпадёт с «включи». Если названы несколько сайтов, выбирается первым упомянутый; при совпадении позиции — самый длинный ключ. Поддерживаются только перечисленные формы, без морфологического разбора.

При отсутствии ключевого слова открывается:

```text
https://www.google.com/search?q=<URL-encoded текст>
```

Пустое распознавание не открывает браузер: приложение предлагает повторить фразу. Неизвестный непустой запрос запускает поиск без уведомления. Google получает текст поискового запроса, но не аудио.

## Автозапуск

Команды создания и удаления ярлыка выполняются **без прав администратора**. Они не запускают запись и не загружают модель.

Включить:

```bat
.venv\Scripts\python.exe main.py --install-startup
```

Включить с выбранными настройками:

```bat
.venv\Scripts\python.exe main.py --install-startup --model small --device cpu
```

Создаётся `VoiceSiteLauncher.lnk` в пользовательской папке `shell:startup`. Ярлык запускает `pythonw.exe` из текущего виртуального окружения с абсолютным путём к `main.py`. Для настройки используется встроенный Windows PowerShell и COM `WScript.Shell`, без внешних скриптов и изменения ExecutionPolicy.

При входе в Windows приложение предупредит о правах и предложит повышение через UAC. **Автозапуск не обходит UAC и не является полностью беззвучным.** Не отмечайте «Запуск от имени администратора» у самого ярлыка: Windows может блокировать повышенные программы автозагрузки; повышение выполняется после обычного запуска Python.

Отключить:

```bat
.venv\Scripts\python.exe main.py --remove-startup
```

Либо нажмите Win + R, введите `shell:startup` и удалите только ярлык `VoiceSiteLauncher.lnk`. Для изменения модели/устройства сначала удалите ярлык и создайте заново. После перемещения проекта или удаления `.venv` автозапуск нужно перенастроить.

Автозапуск **не включён автоматически** при установке зависимостей или обычном запуске.

## Микрофон, ошибки и приватность

- Выберите микрофон по умолчанию в параметрах звука Windows.
- Включите доступ настольных приложений к микрофону в разделе конфиденциальности.
- Устройство должно принимать mono 16 кГц; при несовместимости появится сообщение.
- Ошибки микрофона, пустая речь и ошибки распознавания отображаются уведомлением трея. При недоступности уведомлений применяется MessageBox.
- Ошибки первой загрузки модели: проверьте интернет, свободное место и доступ к хранилищу моделей, затем перезапустите приложение.

**Аудиофайлы вообще не создаются.** Звуковые фрагменты находятся в RAM; промежуточные фрагменты очищаются при сборке записи, исходный массив — сразу после распознавания, в том числе при ошибке. Это не гарантия криминалистического уничтожения всех внутренних копий CTranslate2 или страниц файла подкачки Windows.

Журнал:

```text
%LOCALAPPDATA%\VoiceSiteLauncher\app.log
```

Он содержит время, распознанный текст, открытый URL и ошибки, но не аудио. Размер ограничен 1 МБ плюс две резервные копии. **Текст речи и поисковые запросы остаются в журнале.** Не диктуйте секреты; при необходимости удалите журналы после выхода из программы или уберите строку `logger.info("Текст: ...")` в `main.py`.

## Проверка

```bat
.venv\Scripts\python.exe -m unittest -v test_app
```

Тесты подменяют микрофон, браузер и клавиатурный hook: проверяют оба порядка нажатия/отпускания, автоповтор, границы ключевых слов, URL-кодирование, очистку аудиобуферов, ошибки микрофона и переход CUDA → CPU. Реальные клавиши, браузер и микрофон тестами не управляются.

После запуска вручную проверьте: русскую и английскую фразу, неизвестный запрос, отпускание только одной клавиши, тишину и «Выход». Эта проверка зависит от выбранного микрофона, драйверов и поведения активного приложения.
