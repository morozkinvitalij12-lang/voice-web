# VoiceSiteLauncher — один EXE для Windows

Проект переписан на C# / .NET 10. Удерживайте физические **V + F6**, говорите по-русски или по-английски, отпустите **обе** клавиши. Программа работает в системном трее и открывает сайт либо поиск Google. Облачных STT нет.

## Какой файл запускать

**`publish\VoiceSiteLauncher.exe`** — единственный файл для передачи. Его можно перенести в постоянную папку; Python, .venv и установленный .NET не нужны. Исходный GitHub ZIP сам по себе не содержит готовый бинарный дистрибутив.

1. Запустите EXE двойным кликом.
2. Подтвердите предложение повышения прав и запрос Windows UAC. Отмена завершает приложение; защита не обходится.
3. В первый раз подождите скачивания модели, затем загрузки. Аудио в интернет не отправляется.
4. Дождитесь зелёного микрофона справа внизу. Скрытый значок находится под стрелкой области уведомлений. Постоянную видимость настраивает Windows.
5. Для завершения: правая кнопка на значке → **«Выход»**.

Требования библиотеки Whisper.net 1.9.1: Windows 11 x64 / Server 2022 или новее. Windows 10 этой версией не гарантируется. CRT/OpenMP x64 DLL включены в EXE; Visual C++ Redistributable на компьютере пользователя не нужен. Windows UCRT поставляется ОС. SmartScreen может предупредить о неподписанном EXE.

## Горячие клавиши

Запись начинается после нажатия второй клавиши в любом порядке. Отпускание только одной **не останавливает** запись; нужно отпустить обе. Автоповтор не начинает новую запись; повторное нажатие первой клавиши, пока вторая удерживается, продолжает текущую. Во время распознавания новые записи не принимаются.

Физические scan-коды: V `0x2F`, F6 `0x40`; в русской раскладке V соответствует «М». Ввод читается через **Raw Input**, а не глобальный клавиатурный хук: система не прогоняет каждое нажатие через callback приложения, и античиты игр не видят низкоуровневый перехват от администратора. Клавиши не подавляются: V может вводиться, F6 — выполнять действие в активной программе. Не используйте сочетание в поле пароля. После потери событий при блокировке Windows нажмите и отпустите обе клавиши либо перезапустите приложение. Защищённые игры и античиты могут не передавать события; обхода их защиты нет.

Цвета: серый — подготовка/выход, зелёный — готовность, красный — запись/ошибка запуска, жёлтый — распознавание. Минимум записи 0,25 секунды, максимум буфера 120 секунд. Пустая речь вызывает уведомление; неизвестный непустой текст открывает поиск Google без уведомления.

## Локальный Whisper и CUDA

Python/faster-whisper/CTranslate2 заменены на **Whisper.net 1.9.1 / whisper.cpp**. Это другой локальный движок Whisper, не запуск Python и не облачный сервис. По умолчанию используется модель **small** — она заметно точнее base, особенно для русского и при фоновом шуме. Распознавание ограничено **только русским и английским**: язык выбирается автоопределением среди двух кандидатов (ru/en), причём английский берётся только при уверенной детекции (вероятность ≥ 0.75), иначе русский. Это убирает ложное «русский → английский» на коротких и шумных фразах. Транскрипция идёт **beam search** (точнее greedy). Можно явно выбрать base или устройство:

```bat
VoiceSiteLauncher.exe --model base
VoiceSiteLauncher.exe --device cpu
VoiceSiteLauncher.exe --model base --device cpu
```

Модель **не встроена** в EXE. По умолчанию используется small (~488 МБ), base ~148 МБ; модель один раз скачивается в `%LOCALAPPDATA%\VoiceSiteLauncher\models`, затем распознавание работает офлайн. Первый запуск с small требует загрузки ~488 МБ. Незавершённая загрузка сохраняется как .part и заменяет модель только после проверки размера. Для офлайн первого запуска заранее положите ggml-small.bin (или ggml-base.bin) формата Whisper.net в эту папку. Кэш прежнего faster-whisper имеет другой формат.

Auto пробует CUDA только если в системе есть драйвер NVIDIA и CUDA Toolkit 13; режим cuda также допускает CPU fallback. **CUDA-рантайм не входит в EXE**: при обнаружении тулкета он один раз скачивается (~140 МБ) с NuGet в `%LOCALAPPDATA%\VoiceSiteLauncher\runtime`, проверяется по SHA512 и кешируется. Без драйвера/тулкета скачивания нет — сразу CPU. Сам загрузчик Whisper дополнительно проверяет версию cudart и наличие GPU и при неудаче переходит на CPU. Для GPU нужны совместимая карта/драйвер и CUDA Toolkit 13.0.1 или новее. Ошибка GPU при распознавании приводит к пересозданию контекста с UseGpu=false и повтору той же записи. Наличие CUDA DLL не доказывает фактическое выполнение на GPU.

Во время распознавания CPU нагружается заметно (beam search, модель small, до ~12 потоков) — это плата за точность на время фразы. **В фоне потребление минимально**: микрофон закрыт, загруженная модель в покое не считает, обработка идёт только при удержании V + F6; фоновые задачи — лишь редкий таймер простоя и Raw Input (микросекунды на нажатие). CPU-бэкенд требует AVX/AVX2/FMA — этим обладают все процессоры, поддерживаемые Windows 11; отдельный NoAvx-рантайм убран из EXE ради размера. Модель выгружается из памяти после 5 минут простоя и загрувается заново при следующей фразе (задержка первой фразы после простоя с small выше); между фразами ОЗУ почти не расходуется. При выходе запись останавливается; приложение дожидается текущего распознавания и освобождения нативного процессора, затем отбрасывает результат. Значок остаётся до завершения; это может занять время на CPU. После запроса выхода браузер не открывается.

## Сайты

Словарь `SiteRouter.cs`: YouTube, Google, VK, Telegram Web, Wikipedia, GitHub, Stack Overflow, Reddit, Twitch, Ozon, Wildberries, Avito, Habr. Текст нормализуется: нижний регистр, одиночные пробелы. Границы слов не позволяют «вк» совпасть с «включи». Выбирается первый упомянутый сайт, при одинаковой позиции — самый длинный ключ. Без совпадения Google получает URL-кодированный запрос. Сайт открывается через оболочку Windows в браузере по умолчанию.

## Автозапуск

```bat
VoiceSiteLauncher.exe --install-startup
VoiceSiteLauncher.exe --install-startup --model small --device cpu
VoiceSiteLauncher.exe --remove-startup
```

Эти команды обрабатываются до повышения прав, без модели, hook и микрофона. Создаётся VoiceSiteLauncher.lnk в пользовательской папке shell:startup, на **реальный EXE**, а не временный каталог распаковки. Автозапуск по умолчанию выключен. Существующий ярлык не перезаписывается. UAC при входе не обходится. После перемещения EXE удалите ярлык и создайте заново.

## Микрофон и приватность

Выберите микрофон по умолчанию и разрешите доступ настольных приложений в настройках Windows. WinMM записывает PCM16 mono 16 кГц; несовместимость формата/устройства вызывает уведомление. В ожидании микрофон не открыт.

**Аудиофайлы не создаются.** Запись идёт в один предаллоцированный RAM-буфер (до 120 секунд), который передаётся Whisper напрямую через `ReadOnlyMemory` без второй копии и очищается после обработки, ошибок и выхода. Пик ОЗУ на запись ограничен размером буфера. Это не гарантия уничтожения внутренних копий движка и страниц файла подкачки ОС.

Журнал `%LOCALAPPDATA%\VoiceSiteLauncher\app.log`: время, ошибки, текст речи и URL, не аудио. Лимит 1 МБ плюс две резервные копии. Не диктуйте секреты. Google получает текст неизвестного запроса, но не аудио. Windows может скрывать уведомления в режиме «Не беспокоить»; ошибки запуска также видны по красному значку и журналу.

Один EXE — один файл для передачи, не отсутствие файлов после запуска. .NET и native DLL автоматически распаковываются во временную пользовательскую папку .net; модель и журнал — в LocalAppData. DLL не нужно переносить рядом с EXE.

## Сборка

Для разработчика: SDK .NET 10 x64 и Microsoft Visual C++ 2022 x64 Redistributable на машине сборки. Нужны vcruntime140.dll, vcruntime140_1.dll, msvcp140.dll, vcomp140.dll: они включаются в EXE и предзагружаются по абсолютным путям. Можно задать `-p:VCRuntimeDirectory=путь_к_x64_CRT`.

```bat
dotnet publish VoiceSiteLauncher.csproj -c Release -r win-x64 --self-contained true -m:1 -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o publish
```

Native CPU assets сохраняют дерево каталогов. IncludeAllContentForSelfExtract позволяет Whisper найти DLL после распаковки. CUDA-рантайм в сборку не входит и скачивается приложением по требованию. Выходной файл: publish\VoiceSiteLauncher.exe.

Модули: Program.cs, TrayApplication.cs, PushToTalk.cs, RawInput.cs, AudioRecorder.cs, SpeechRecognizer.cs, CudaRuntime.cs, SiteRouter.cs, StartupShortcut.cs, AppLog.cs. Проект: VoiceSiteLauncher.csproj и app.manifest. Тесты: Tests (RouterTests, HotkeyTests, OptionsTests, RecorderTests, RawInputTests).

Прежняя Python-реализация сохранена локально в игнорируемой .legacy-python, не требуется для C# и не включается в EXE. Подготовленная копия в другой папке и пользовательские запущенные экземпляры не изменялись.

## Статус проверки

Юнит-тесты пройдены: 101 из 101 (xunit, `dotnet test Tests/VoiceSiteLauncher.Tests.csproj -c Release`). Покрыты маршрутизация сайтов и Google-fallback, семантика V + F6, разбор аргументов, парсер Raw Input, выбор языка ru/en (смещение к русскому) и рекордер на подставном устройстве захвата — без реального микрофона, клавиатуры и браузера. Также проведены статические ревью и сборка single-file EXE.

Оптимизированная версия (опциональная CUDA, idle-выгрузка модели, языки ru/en со смещением к русскому, модель small + beam search, Raw Input, один аудиобуфер) **не запускалась в рантайме**: пользователь играет, реальный запуск отложен. Сборка и тесты не подтверждают работу реального микрофона, V + F6 через Raw Input, трея, CUDA-докачки, UAC, автозапуска, браузера и фактическую точность распознавания на конкретном ПК. Runtime-проверка отложена до разрешения пользователя.
